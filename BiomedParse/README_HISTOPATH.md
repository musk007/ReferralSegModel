# Histopathology Referral Segmentation — BiomedParse v1 Integration

## Overview

This module integrates five multi-dimensional histopathology segmentation datasets
(colon, BCSS breast, breast cells, lung, prostate) into the [BiomedParse v1](https://github.com/microsoft/BiomedParse/tree/main)
fine-tuning pipeline. Each region is described by up to four reasoning dimensions:

| Dimension | Key in JSON | Description |
|---|---|---|
| Histological | `Histological Reasoning` | Morphological/cytological features |
| Spatial | `Spatial Reasoning` | Location relative to landmarks |
| Hierarchical | `Hierarchical Reasoning` | Rank within the image (largest, most complex) |
| Ambiguity | `Ambiguity Reasoning` | Disambiguation from similar neighbours |

## Step-by-Step Setup

### 1. Prepare image and mask files

BiomedParse requires **1024×1024 PNG** images and binary masks.

On-disk folder structure under `biomedparse_datasets/`:
```
biomedparse_datasets/
    colon/
        train/         ← images
        train_mask/    ← binary masks
        train.json     ← generated by convert_histopath_to_biomedparse.py
        test/
        test_mask/
        test.json
    breast_bcss/    (same structure)
    breast_cells/   (same structure)
    lung/           (same structure)
    prostate/       (same structure)
```

> **Target name convention:** spaces → `+`, underscores → `+`, no special chars.
> Example: `"invasive tumor"` → target `invasive+tumor`

---

### 2. Convert annotation JSONs to BiomedParse format

Run from the `BiomedParse/` root:

```bash
BASE=/home/roba/miccai26

# Colon train + test
python convert_histopath_to_biomedparse.py \
    --input   /path/to/colon_train.json \
    --dataset_type colon --split train \
    --output_json ${BASE}/biomedparse_datasets/colon/train.json \
    --images_dir  ${BASE}/biomedparse_datasets/colon/train \
    --prompt_mode all
    --combine_dimensions

python convert_histopath_to_biomedparse.py \
    --input   ${BASE}/test_data/test_split/instructions/colon.json \
    --dataset_type colon --split test \
    --output_json ${BASE}/biomedparse_datasets/colon/test.json \
    --images_dir  ${BASE}/biomedparse_datasets/colon/test \
    --prompt_mode all
    --combine_dimensions

# Repeat for: breast_bcss (--dataset_type bcss),
#             breast_cells (--dataset_type breast_cells),
#             lung (--dataset_type lung),
#             prostate (--dataset_type prostate)
```

Test source JSONs for all datasets live in:
```
test_data/test_split/instructions/{colon,lung,prostate,breast_bcss,breast_cells}.json
```

#### Ablation JSONs (one per dimension)

```bash
python run_ablation_conversion.py \
    --colon_json    /path/to/colon.json \
    --bcss_json     /path/to/breast_bcss.json \
    --lung_json     /path/to/lung.json \
    --prostate_json /path/to/prostate.json \
    --splits train test \
    --output_root   ../biomedparse_datasets
```

The `datasets/registration/register_biomed_datasets.py` maps on-disk folder names to

| Registered name | On-disk folder |
|---|---|

| `biomed_HistoPathCells_train/test` | `biomedparse_datasets/breast_cells/` |
| `biomed_HistoPathLung_train/test` | `biomedparse_datasets/lung/` |
| `biomed_HistoPathProstate_train/test` | `biomedparse_datasets/prostate/` |
| `biomed_HistoPathAll_train/test` | union of all five above |
| `biomed_BiomedParseAll_train/test` | union of all BiomedParse official datasets |
| `biomed_CombinedFull_train/test` | BiomedParse official + all five histopath |

Registration happens automatically when the file is imported — no extra action needed.

---

### 4. Configure training

`biomed_seg_lang_v1_histopath_full.yaml` is the primary training config (loaded second
via `--conf_files`). Key settings:

```yaml
# Dataset selection
DATASETS.TRAIN: ["biomed_HistoPathAll_train"]
DATASETS.TEST:  ["biomed_HistoPathAll_test"]

# Prompt behaviour
DATASETS.PROMPT_COMBINE: false   # true → join all dimension sentences into one prompt
                                  # false → randomly sample one sentence per step (default)

# LoRA fine-tuning
SOLVER.LORA:
  ENABLED: true
  R: 8
  ALPHA: 16
  TARGET_MODULES: ["lang_encoder", "predictor"]
  DROPOUT: 0.0

# Learning rates
SOLVER.BASE_LR: 0.00000001
SOLVER.LR_MULTIPLIER:
  backbone: 0.1
  pixel_decoder: 0.2
  predictor: 0.5
  lang_encoder: 1.0
```

To train on all data (BiomedParse official + histopath), replace the dataset lines with:
```yaml
DATASETS.TRAIN: ["biomed_CombinedFull_train"]
DATASETS.TEST:  ["biomed_CombinedFull_test"]
```

### 5. Run training

```bash
sbatch /home/roba/runner_full.sh
```

To train on a single dataset:
```bash
TRAIN_DATASET=colon sbatch /home/roba/runner_full.sh
# Options: colon | lung | prostate | breast_bcss | breast_cells
```

Checkpoints are saved to `BiomedParse/output/histopath_full/`.

## LoRA Fine-tuning

LoRA wraps `nn.Linear` layers in `TARGET_MODULES` with low-rank adapters
(`lora_A`, `lora_B`). During training, base model weights are frozen and only
`lora_A`/`lora_B` are updated.

**How it works end-to-end:**
1. `XDecoderPipeline.initialize_model()` calls `apply_lora_to_model()` after `build_model()`.
2. `xdecoder_trainer.py` freezes all parameters, then unfreezes `lora_A`/`lora_B`.
3. Pretrained checkpoint weights load via key remapping in `utilities/model.py`:
   `xxx.mlp.0.weight` → `xxx.mlp.0.linear.weight` (original weight inside `LinearLoRA`).
4. `lora_A`/`lora_B` are randomly initialised (not loaded from checkpoint).

**Enable / disable:**
```yaml
SOLVER.LORA:
  ENABLED: true   # set false to do full fine-tuning instead
```

## JSON Format Reference

### Input format (GPT annotation files)

**Colon:**
```json
{ "testA_1": { "diagnosis": "adenomatous", "regions": {
    "testA_1_query_mask_largest_contoured": { "gpt": { "glands": {
        "testA_1_query_mask_largest_contoured": {
            "Histological Reasoning": ["..."],
            "Spatial Reasoning":      ["..."],
            "Hierarchical Reasoning": ["..."],
            "Ambiguity Reasoning":    ["..."]
        }
    }}}
}}}
```

**BCSS / Prostate (flat):**
```json
{ "image_key": { "regions": {
    "region_key": { "gpt": {
        "Histological Reasoning": ["..."],
        "Ambiguity Reasoning":    ["..."],
        "region_class": "invasive tumor"
    }}
}}}
```

**Lung (one nesting level):**
```json
{ "00": { "regions": {
    "image_00_0": { "gpt": {
        "Tumor epithelium": {
            "Histological Reasoning": ["..."],
            "Ambiguity Reasoning":    ["..."]
        },
        "region_class": "tumor epithelium"
    }}
}}}
```

### Output format (BiomedParse train.json / test.json)

```json
[
  {
    "image_name": "testA_1.bmp",
    "mask_name":  "testA_1_query_mask_largest.png",
    "sentences": [
      {"sent": "Segment the large, branching adenomatous gland..."},
      {"sent": "Select the dominant, centrally located villous gland..."},
      {"sent": "Isolate the largest and most expansive glandular structure..."},
      {"sent": "Identify the villous gland whose fronds contain..."}
    ]
  }
]
```
